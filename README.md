# 🏰 Mansions adventure - Python Text Adventure

Een interactief, tekstgebaseerd avonturenspel geschreven in Python. De speler bevindt zich in een mysterieus huis en moet door verschillende kamers navigeren, keuzes maken en monsters verslaan om de uitgang te vinden.

## 🗺️ Het Spel & Structuur
Het spel daagt de speler uit om logisch na te denken. Elke kamer heeft zijn eigen omschrijving, gevaren en keuzes. 

De speler navigeert door middel van tekstcommando's (zoals `noord`, `zuid`, etc.).

## Conceptuele opzet van de kamers:

* **Kamer 1 (De Start):** De speler ontwaakt en moet een eerste richting kiezen.
* **Kamer 2 (De Uitdaging):** Een kamer met een monster of een item dat opgelost/opgepakt moet worden.
* **Kamer 3 / De Uitgang:** Het uiteindelijke doel van het spel.

## Toegepaste Python Concepten
Dit project laat zien hoe fundamentele programmeerlogica wordt gebruikt om een interactieve wereld te bouwen:
* **Dictionaries:** De mansion is opgebouwd via een dictionary.
* **Gebruikersinvoer (`input()`):** Het script reageert dynamisch op wat de speler intypt.
* **Conditionele Logica (`if / elif / else`):** Bepaalt de consequenties van de keuzes van de speler (bijv. levens verliezen, spullen oppakken of een andere kamer betreden).
* **While-loops:** Om het spel draaiende te houden totdat de speler wint of afgaat.
